# 0x15. JavaScript - Web Interactive

This project focuses on building interactive web pages using **vanilla JavaScript only** (no jQuery or external libraries). It covers DOM manipulation, event handling, and fetching data from APIs.

## Requirements

- All files are interpreted in a modern browser.
- Code must be semistandard compliant (no `var`, proper spacing).
- No full page reloads for DOM updates or data fetches.
- Each HTML file loads its corresponding JavaScript file at the end of the `<body>`.

## Files

| File | Description |
|------|-------------|
| `0-script.js` | Updates the text color of the `<header>` element to red (`#FF0000`). |
| `1-script.js` | Updates the `<header>` to red and all `<p>` elements to green (`#00FF00`). |
| `2-script.js` | Updates the `<header>` text color to red on click of `DIV#red_header`. |
| `3-script.js` | Adds the class `red` to the `<header>` on click of `DIV#red_header`. |
| `4-script.js` | Toggles the `<header>` class between `red` and `green` on click of `DIV#toggle_header`. |
| `5-script.js` | Adds a new `<li>Item</li>` to `UL.my_list` on click of `DIV#add_item`. |
| `6-script.js` | Updates the `<header>` text to "New Header!!!" on click of `DIV#update_header`. |
| `7-script.js` | Fetches a Star Wars character name from an API and displays it in `DIV#character`, handling errors gracefully. |
