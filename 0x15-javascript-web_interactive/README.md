# 0x15. JavaScript - Web Interactive

This project covers DOM manipulation and interactivity using **vanilla JavaScript only** — no jQuery, no external libraries.

## Requirements

- Vanilla JavaScript only (no jQuery or external libraries)
- No `var` — use `const` or `let`
- All files end with a new line
- HTML must not reload for each action

## Files

| File | Description |
|------|-------------|
| `0-script.js` | Updates the text color of the `<header>` element to red (`#FF0000`). |

## Usage

Open `0-main.html` in any modern browser. The header text should appear in **red**.
